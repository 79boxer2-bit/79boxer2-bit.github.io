# 네이버 광고 순위 감시 (사무실 PC용)

같은 매물을 다른 부동산이 우리보다 위에(또는 더 최신 확인일자로) 올리면 카카오톡으로 알려 줍니다.

- 실행 시간: 오전 10시~저녁 6시, 30분마다 (PC가 켜져 있을 때만)
- 재광고는 건당 비용이 들어서 **자동으로 누르지 않습니다.** 알림을 보고 이실장에서 직접 재광고하세요.
- 같은 경쟁 광고로는 **한 번만** 알립니다(하루 최대 20건).
- 재광고하면 다음 점검 때 감지해서 **"직방도 갱신하세요"** 알림을 보냅니다.
- 저녁 6시에 **오늘 요약**을 보냅니다.

## 가장 쉬운 설치: 파일 하나 더블클릭
1. https://github.com/79boxer2-bit/79boxer2-bit.github.io/blob/main/monitor/setup.bat 를 열고, 오른쪽 위 **다운로드 아이콘(Download raw file)** 을 누릅니다.
2. 받은 `setup.bat` 을 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누르세요.
3. 화면 안내대로 진행하면 Python 설치, 프로그램 내려받기(`C:\HaneulAdMonitor`), 단지 주소 입력, 테스트, 자동 실행 등록까지 한 번에 끝납니다.
4. 카카오톡 연결만 아래 **5단계**를 따로 해 주세요.

프로그램을 새 버전으로 바꿀 때도 `setup.bat` 을 다시 실행하면 됩니다(설정은 그대로 유지).

## 직접 설치 (자동 설치가 안 될 때)

### 1단계. Python 설치
1. https://www.python.org/downloads/ 에서 **Download Python** 버튼을 눌러 설치 파일을 받습니다.
2. 설치 첫 화면 아래쪽 **"Add python.exe to PATH"** 를 꼭 체크하고 **Install Now** 를 누릅니다.

### 2단계. 프로그램 받기
1. https://github.com/79boxer2-bit/79boxer2-bit.github.io 에서 초록색 **Code → Download ZIP** 을 누릅니다.
2. 압축을 풀고 `monitor` 폴더를 `C:\하늘광고감시` 처럼 찾기 쉬운 곳에 복사합니다.

### 3단계. 단지 주소 넣기
1. `config.example.json` 을 복사해서 이름을 **`config.json`** 으로 바꿉니다.
2. 메모장으로 `config.json` 을 엽니다.
3. 네이버 부동산에서 단지를 하나씩 검색해 단지 화면을 열고, **주소창의 주소를 복사**해서 해당 단지의 `"url": ""` 따옴표 안에 붙여 넣습니다.
   - 예: `"url": "https://new.land.naver.com/complexes/12345"`
   - 모바일 주소(`m.land.naver.com/complex/info/12345`)도 됩니다. 숫자만 넣어도 됩니다.
4. 저장합니다.

### 4단계. 테스트
`monitor` 폴더 주소창에 `cmd` 라고 치고 Enter → 까만 창에서:
```
python ad_monitor.py test
```
첫 단지의 매물 순위가 쭉 나오고 **"우리 매물 N건"** 이 1건 이상이면 정상입니다.
안 되면 화면을 캡처하고, 생긴 `debug` 폴더도 같이 보내 주세요.

### 5단계. 카카오톡 연결
1. https://developers.kakao.com 에 카카오 계정으로 로그인 → **내 애플리케이션 → 애플리케이션 추가** (앱 이름: 하늘광고감시).
2. 앱 화면의 **REST API 키**를 복사해서 `config.json` 의 `"rest_api_key"` 에 넣습니다.
3. **카카오 로그인** 메뉴에서 활성화를 **ON**, Redirect URI에 `https://localhost` 를 등록합니다.
4. **동의항목**에서 **카카오톡 메시지 전송(talk_message)** 을 '선택 동의'로 켭니다.
5. **플랫폼 → Web** 사이트 도메인에 `https://m.land.naver.com` 을 등록합니다(알림의 '매물 보기' 버튼용).
6. 까만 창에서:
   ```
   python ad_monitor.py kakao-login
   ```
   브라우저가 열리면 동의 → '사이트에 연결할 수 없음' 화면이 나오면 **주소창 주소를 통째로 복사**해 까만 창에 붙여 넣고 Enter.
7. `python ad_monitor.py kakao-test` → 카카오톡 **'나와의 채팅'** 에 테스트 메시지가 오면 완료.

※ 카카오 개발자 사이트 메뉴 이름은 바뀔 수 있습니다. 헷갈리면 화면을 캡처해 주세요.
※ 카카오 연결은 **2개월 이상 쓰지 않으면 끊깁니다.** 매일 돌리면 자동으로 연장됩니다. 끊기면 6번만 다시 하면 됩니다.

### 6단계. 자동 실행 등록
`install_task.bat` 을 더블클릭합니다. "등록 완료"가 나오면 끝입니다.
- 끄기: `uninstall_task.bat` 더블클릭
- 기록 보기: `monitor.log` (메모장)

## 알림 예시
```
[광고 밀림] 시티프라디움1차 111동 5/25
매매 4억 3,000 · 전용 84㎡
○○부동산 1위(09/30)
우리 3위(09/28)
→ 이실장에서 재광고 검토
```

## 같은 매물 판단 기준
같은 단지·동·거래형태·전용면적(±1㎡)이면서
- 층이 둘 다 숫자로 나오면 **같은 층**,
- 한쪽이 저/중/고로만 나오면 **같은 층대 + 같은 가격**
일 때 같은 매물로 봅니다. 가격이 다르면 알림에 "다른 호수일 수 있음"을 붙입니다.
